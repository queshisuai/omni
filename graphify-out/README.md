# Project Knowledge Graph

This directory stores shareable Graphify knowledge graph artifacts for the project.

Tracked artifacts:

- `graph.json` - machine-readable project graph.
- `graph.html` - interactive graph viewer.
- `GRAPH_REPORT.md` - generated graph summary report.
- `cost.json` - generation cost summary.

Local Graphify cache and intermediate files are intentionally ignored because they can contain machine-local absolute paths.
