# SeatCraft 使用文档

## 界面概览

SeatCraft 的界面分为三个区域：

- **左侧导航栏**：模式切换（选座/设计）及辅助工具
- **中央画布**：座位图渲染区，支持缩放平移
- **右侧控制面板**：分区属性编辑或已选座位列表

---

## 模式切换

### 设计模式（Design Mode）

用于编辑场馆布局。点击左侧导航栏的 **Move (十字箭头)** 图标进入。

在设计模式下可以：
- 拖拽移动舞台位置
- 拖拽移动每个座位分区
- 添加、删除、复制分区
- 调整分区参数
- 切换模板

### 选座模式（Selection Mode）

用于模拟用户购票选座。点击左侧导航栏的 **MousePointer (鼠标指针)** 图标进入。

在选座模式下可以：
- 点击座位进行选择/取消
- 缩放平移查看画布
- 查看已选座位列表及汇总

---

## 模板系统

点击顶部工具栏的模板按钮可快速切换：

| 模板 | 说明 |
|------|------|
| **演出场地** | 预设池座内场 + 环绕看台（圆弧布局） |
| **影院模式** | 预设观影大厅 + 核心优选区 |
| **清空画布** | 仅保留舞台，无分区，从零开始设计 |

---

## 分区编辑（设计模式）

### 添加分区

点击顶部右侧的 `ADD_SECTION` 按钮，将在画布中央新建一个默认分区。

### 选中分区

每个分区在右侧面板中对应一个控制卡片。点击卡片上的参数即可编辑。

### 分区参数说明

| 参数 | 说明 |
|------|------|
| **名称** | 分区的显示名称（支持中文） |
| **类型** | 核心区 / 看台 / 普通（影响边框颜色） |
| **颜色** | 座位的填充颜色（5 种预设色） |
| **布局** | 方阵（Grid）或 圆弧（Curved） |
| **排数/座数** | 调整行列数量 |
| **旋转角度** | 0°~360° 自由旋转 |

### 布局类型

**方阵布局 (Grid)**：矩形排列，适合池座、普通厅。

**圆弧布局 (Curved)**：扇形/弧形排列，适合环绕看台。额外参数：
- **半径**：内圈半径，值越大弧形越平缓
- **弯曲跨度**：弧形的角度跨度（30°~360°）

### 核心优选区

在方阵布局下可为分区设置"核心优选区"，该区域座位会以金色高亮显示。点击 **设置** 按钮开启，可分别调整行/列的起止范围。

### 复制与删除

每个分区卡片右上角提供：
- **复制图标**：创建分区的副本（位置偏移 30px）
- **删除图标**：移除该分区

---

## 拖拽操作

### 拖拽舞台

直接拖拽画布中的舞台矩形区域，松开后位置自动保存。

### 拖拽分区

直接拖拽画布中的分区区域，松开后位置自动保存。

> 拖拽仅在 **设计模式** 下可用。

---

## 一键对齐

点击右侧面板顶部的 **一键快速对齐布局** 按钮，系统将自动：
1. 将舞台固定在顶部中央
2. 根据分区 Y 坐标分组行
3. 以画布中心为基准水平居中排列
4. 自动调整间距

---

## 画布浏览

在 **选座模式** 下使用鼠标滚轮缩放，拖拽平移画布查看详情。

在设计模式下缩放平移被禁用，以避免与分区拖拽冲突。

---

## 选座流程

1. 切换到 **选座模式**
2. 缩放/平移找到目标座位区域
3. 点击可选座位（彩色）进行选择
4. 已选座位变为白色高亮，并显示分区名称标签
5. 右侧面板列出所有已选座位及其价格
6. 底部 **结算汇总** 显示已选数量
7. 点击 **确认选座** 完成（当前为模拟操作）

### 座位状态颜色说明

| 颜色 | 状态 |
|------|------|
| 分区色（绿/蓝/紫等） | 可选 |
| 金色 | 优选座位 |
| 白色（发光） | 已选择 |
| 暗灰色 | 已售罄/不可选 |
| 红色 | 已预定 |

---

## 图例

画布底部固定显示图例栏，包含当前所有分区的颜色标识、优选标识、已选标识和售罄标识。

---

## 注意事项

- 设计模式下修改会自动保存到 React 状态，刷新页面会丢失——如需持久化可自行扩展后端存储
- `GEMINI_API_KEY` 仅在使用 Gemini AI 相关功能时需要，核心选座功能无需配置
